One original single-line excuse a developer gives when their code breaks in production — the excuse is "I tested it", and the twist is where it was tested: staging, where the database has one row and the users are all named Test.

> I tested it in staging, where the database has one row and the users are all named Test.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 88 characters, within the 200-character cap.
